No existing value read

KAORI uses inventory only for target identity and key names. It never calls Secret read APIs or displays current values.

Replacement semantics

Blank field
Key is omitted from the patch and its server value remains unchanged.
Entered value
Only that key is submitted and replaced.
Apply action
Always runs Kubernetes server-side dry-run immediately before mutation.

This workflow does not delete keys, write empty-string values, change Secret type, or update immutable Secrets. Blank always means preserve. TLS material remains in the dedicated TLS Rotation workflow.

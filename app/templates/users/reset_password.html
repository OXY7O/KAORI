Credential Ownership by Provider

Local Database

Reset here

LDAP / Active Directory

Reset the credential in LDAP or Active Directory. KAORI stores an identity link and authorization state, not the directory password.

Google OpenID Connect

KAORI receives an authenticated Google identity and does not own a Google password. Use Google's account-recovery process.

GitHub OAuth

KAORI receives a GitHub identity through OAuth and does not store a GitHub password. Recover access through GitHub.

How Each Provider Is Used

Authentication and provisioning behavior differs by provider type.

Details Collapse

LDAP / Active Directory

Administrators search the directory and provision users first. Users authenticate through the normal username and password form; LDAP does not add a separate login button.

Google OpenID Connect

Adds a Google sign-in option when enabled and its client secret is available at runtime. JIT can be restricted by approved email domains.

GitHub OAuth

Adds a GitHub sign-in option when enabled and runtime-ready. Controlled JIT uses approved GitHub logins or immutable numeric user IDs.

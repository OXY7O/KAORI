How To Read Missing Or Non-Applicable Values

A blank operational signal must keep its reason visible. These states are intentionally different.

{{ table_label.status_label('Not Configured', 'info', size='compact') }}

The provider confirms the feature is absent, for example a bucket without a quota. This is actual state, not a collection failure.

{{ table_label.status_label('No Current Samples', 'unknown', size='compact') }}

The worker query was valid but returned no samples in the selected scope or time window.

{{ table_label.status_label('Metric Not Scraped', 'warning', size='compact') }}

The optional metric family is not present in the bound Metrics Source. Bucket request metrics require MinIO /minio/v2/metrics/bucket collection.

{{ table_label.status_label('Runtime Query Failed', 'critical', size='compact') }}

The metric contract exists, but the worker collection query failed. KAORI preserves the failure state instead of converting it into zero or healthy evidence.

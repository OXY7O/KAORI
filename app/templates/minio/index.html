Integration Contract

MinIO-Compatible S3 API

Endpoint identity, authentication, supported release, and core S3 API behavior are validated before operational use.

Consumer Resolution

Asset, Selector, and Profile Aware

Prometheus metrics and Alertmanager alerts are validated independently through object-storage consumer bindings.

Authority Boundary

Each Provider Remains Authoritative

MinIO owns storage state, Prometheus owns metrics, and Alertmanager owns alert delivery; KAORI governs registration and binding evidence.

Membership Model

Membership establishes identity inside a Tenant. It does not grant Kubernetes permissions by itself.

Use User Membership

Best for individually accountable human access. The KAORI user remains the ownership anchor.

Use Tenant Group

Best when the same Kubernetes group subject represents several operators outside KAORI.

Revocation Impact

Revoking membership disables dependent Access Grants; review downstream credential impact first.

Membership Actions

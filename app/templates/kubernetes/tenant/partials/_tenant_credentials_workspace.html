Credential Issuance

Human and CI/CD credentials follow the same governed lifecycle but use different ownership and delivery contracts.

Issue Human Access

Individually owned JumpServer access from a reconciled user grant.

Delivery Contract

Human access is individually owned and delivered through JumpServer unless a governed exception exists.

Issue CI/CD Deployer

Namespace-scoped machine identity for GitHub Actions and Helm delivery.

Delivery Contract

Deployer identity is machine-only, namespace-scoped, and issued for the named delivery application.

Version Configuration

Release identity is deployment metadata, not an editable user preference.

Required variable
APP_VERSION={{ system_information.version }}
Optional build metadata
APP_BUILD_SHA and APP_BUILD_DATE provide immutable release traceability when supplied by the image build or deployment pipeline.
Deployment rule
Keep APP_VERSION aligned with the immutable KAORI image tag to make support and rollback decisions unambiguous.

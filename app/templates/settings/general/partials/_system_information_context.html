Release Governance

Required Variable

Build Traceability
APP_BUILD_SHA and APP_BUILD_DATE identify the immutable release when supplied by the build or deployment pipeline.
Deployment Rule
Keep APP_VERSION aligned with the immutable KAORI image tag so support and rollback decisions remain unambiguous.

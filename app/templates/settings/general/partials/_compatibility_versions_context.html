Policy Boundary

The matrix describes KAORI application compatibility, not the upstream product support calendar.

Source of truth
Versioned profiles in app.integrations.compatibility and provider capability registries.
Activation rule
Unsupported versions are blocked. Compatible versions can still remain degraded until capability validation succeeds.
Upgrade guidance
Use the Recommended Baseline when introducing a new integration or planning an upgrade for maximum KAORI capability coverage.

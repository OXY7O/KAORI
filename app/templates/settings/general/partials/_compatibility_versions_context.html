Policy Boundary

This matrix describes KAORI compatibility, not upstream vendor lifecycle support.

Source of Truth
Versioned profiles in app.integrations.compatibility and provider capability registries.
Activation Rule
Unsupported versions are blocked. Compatible versions may remain degraded until live capability validation succeeds.
Upgrade Guidance
Use the Recommended Baseline for new integrations and planned upgrades when maximum KAORI capability coverage is required.

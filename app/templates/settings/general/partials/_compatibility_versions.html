General Contract Version
Core-vN does not advance every year; it changes only when the stable API or capability contract has a breaking semantic change.
Lifecycle Boundary
Pre-window releases are End of Life. Future versions remain Unverified until the next qualification update, even when core capability probes succeed.
Blocking Rule
End-of-life releases, missing mandatory capabilities, invalid provider identity, or failed live validation remain blocking conditions.

Contract Ownership

Several product versions may share one core contract; qualification does not replace live validation.

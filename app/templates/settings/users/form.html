Identity source guide

Choose where credentials are owned before creating the KAORI account.

Local Database

Available

KAORI stores the account and manages its password. An initial password is required.

LDAP / Active Directory

Prepared

The directory owns the password. KAORI stores only an identity projection, lifecycle state, and assigned role.

SSO / Identity Provider

Prepared

The IdP authenticates the user. KAORI links a stable external subject and applies local lifecycle and authorization controls.

Provisioning flow

Create or project identity → assign role → set lifecycle state → record the administrative action.

External-provider passwords are never entered, stored, or reset by KAORI.

Authentication Paths

How each supported provider authenticates users into KAORI.

Local Database

Username and password are verified by KAORI. This remains the break-glass administration path.

LDAP / Active Directory

Users use the standard username/password form; the directory validates the credential.

Google OpenID Connect

Google authenticates through the SSO button; KAORI enforces identity linking or controlled JIT admission.

GitHub OAuth

GitHub authenticates through the SSO button; KAORI enforces the linked subject or controlled JIT allow-list.

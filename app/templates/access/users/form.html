Complete This Form
  1. 1. Enter the KAORI identity profile and initial password.

  3. 3. Submit this form; KAORI becomes the credential owner.

Use Directory Provisioning
  1. 1. Open Directory Provisioning and select the configured directory provider.
  2. 2. Search and select the authoritative directory identity.
  3. 3. Assign KAORI access; The directory retains password ownership.

Google or GitHub SSO

Use SSO Admission
  1. 1. Enable and validate the required identity provider.
  2. 2. Configure controlled JIT admission or link an existing external identity.
  3. 3. The user signs in through the provider; KAORI applies the admitted role and lifecycle controls.

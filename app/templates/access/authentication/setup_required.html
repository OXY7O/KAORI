Initialization Path

Follow the bootstrap sequence once from the KAORI Dev Container. The readiness page does not mutate database state.

  1. 01

    Confirm the encryption boundary

    Set INTEGRATION_CREDENTIAL_KEY before migration and keep the same value after encrypted integration credentials are created.

  2. 02

    Run the Initial KAORI Database Bootstrap

    Apply the migration chain, seed canonical RBAC, and bootstrap the first local administrator in one controlled command.

  3. 03

    Return to the readiness check

    Retry setup after bootstrap completes. KAORI will admit the normal sign-in flow only when the required schema is present.

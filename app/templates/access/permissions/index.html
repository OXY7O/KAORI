How RBAC Is Applied

Permissions define capabilities, roles package them, and User Management assigns one role to a user.
  1. 1

    Permission Catalog

    Backend-defined permission keys are synchronized to the database by flask seed-rbac. The catalog is read-only in the UI.

  2. 2

    Roles & Access

    Selected permission keys are bundled into protected default roles or administrator-managed custom roles.

  3. 3

    User assignment

    User Management assigns one active role to each account. Identity Providers may supply a configured default role during JIT provisioning.

  4. 4

    Server enforcement

    Route and service guards evaluate the authenticated user's active role. Super Admin remains a separate emergency authority flag.

Security boundary: server-side permission checks are authoritative. Hidden navigation and disabled controls only improve usability.

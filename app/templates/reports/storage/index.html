Configuration Guide

Local backend

Set REPORT_STORAGE_BACKEND=local and optionally REPORT_LOCAL_STORAGE_DIR. Best for local development or single-node deployment. Artifact keys are namespaced by report family, for example reports/kubereport/kubernetes/....

S3-compatible backend

Set REPORT_STORAGE_BACKEND=s3, bucket, region, endpoint for MinIO if needed, and credentials through ENV or Kubernetes Secrets. The same bucket can later separate kubereport/kubernetes from serverreport/vm or serverreport/hci prefixes.

Telegram Bot API

Create a bot with BotFather, add it to the intended chat/group/channel, then enter the token and destination. Test Delivery verifies both credential and destination access.

SMTP Email

Use an internal SMTP relay or authenticated SMTP service. STARTTLS is the recommended default; TLS/SMTPS and trusted-relay mode are also supported.

Separate multiple recipients with commas.

Microsoft Teams Workflows

Create a Teams Workflow using “When a Teams webhook request is received”, copy its webhook URL, and keep at least one co-owner for operational continuity. KAORI does not support legacy Office 365 connector webhook URLs.

Current KAORI delivery uses the Workflow trigger configured for Anyone authentication, so no bearer token is sent. Treat the webhook URL as a secret; KAORI encrypts it at rest and never renders it back.

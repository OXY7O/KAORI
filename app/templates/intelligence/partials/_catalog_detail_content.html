How Alert Escalation Works

These controls decide when recommendation evidence becomes operator-owned Alert Intelligence work.

Escalation Mode
Manual waits for an authorized operator to promote an eligible finding. Automatic promotes only after every configured rule threshold is satisfied.
Grouping
Controls how eligible findings share Alert Cases: one case per Finding, Rule + Asset + Scope, or one aggregated Rule + Asset case.
Stability Window
Minimum continuous time an automatic finding must remain eligible before KAORI can promote it, reducing short-lived alert noise.
Minimum Observations
Minimum committed evaluation count required for automatic promotion so one isolated observation cannot immediately create an Alert Case.

Info findings remain recommendation-only below the rule-owned Alert Severity Floor. Manual promotion is allowed only after that floor is met; Automatic mode additionally enforces the Stability Window and Minimum Observations.

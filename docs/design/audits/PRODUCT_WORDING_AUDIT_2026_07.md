# Product Wording Audit — July 2026

## Scope

The audit reviewed product-facing templates and runtime messages for generic references to the KAORI product.

## Applied normalization

Generic product references were replaced with direct KAORI wording in these areas:

- Retention and archive readiness.
- Notification/database failure guidance.
- Alertmanager operational errors.
- General Settings system and timezone guidance.
- Permission Catalog descriptions.
- Access-denied guidance.
- Alertmanager endpoint help text.

## Preserved contextual uses

The audit intentionally retained **application** where it means:

- Kubernetes application workloads.
- External OAuth/OIDC applications.
- Application owners or business applications.
- MIME types and protocol terminology.
- Internal architecture terminology where product branding would reduce precision.

## Ongoing rule

Future UI copy must use **KAORI** when the product is the subject or object. Generic wording requires a real technical reason and must not be used merely as a synonym for KAORI.

# Analytics Storage and Forecast Guidance Standard

## Confirmed decisions

1. Persistent Storage Snapshot should not leave a large empty area beneath the utilization reading.
2. That space is filled with guidance blocks using the same icon-led interpretation pattern as the other Analytics overview panels.
3. Forecast Decision belongs with the other forecast interpretation blocks below the chart, not isolated in the Resource Outlook side panel.
4. Forecast interpretation blocks may expand to three columns on wide screens: How To Read, What To Do, and Forecast Decision.

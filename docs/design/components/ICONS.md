# Icon Standard

Recommended sizes:
- Hero: 24 px.
- Card/major block: 20 px.
- Section/table block: 18 px.
- Resource title: 16–18 px.
- Inline/action: 14–16 px.
- Status label: 12 px.

Icons are contextual, not mandatory. Do not decorate every value. For a two-line title cell, use a 40 x 40 px container and an 18 px icon. For a one-line title, use a 32 x 32 px container and a 16 px icon.

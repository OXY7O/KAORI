# KAORI Section Header Action Standard

## Purpose

`section_link_button.html` is the compact link action used in a card or operational section header.

## Visual contract

- height 36 px (`h-9`);
- `rounded-lg`;
- `text-xs font-semibold`;
- standard surface and border;
- Violet hover/focus treatment;
- icon after the label;
- one action maximum per section header.

This is an explicit exception to the normal 40 px page/form action geometry. It must not be used as the primary page action or inside a table row.

# Analytics Overview Review Notes

## Confirmed standard

1. Analytics hero metadata is capped at **three labels maximum**, including the cluster scope label.
2. Analytics Overview right posture card follows the Inventory hero composition:
   - eyebrow
   - posture value using the Inventory-sized title scale
   - maximum two compact metrics
   - one full-width `Manage Clusters` action
   - no descriptive notice panel under the posture value
3. Overview interpretation blocks such as `Operational Reading`, `How To Read`, `What To Do`, and `Recommended Review Path` use the Capacity-style icon-led guidance presentation with a semantic status color when applicable.

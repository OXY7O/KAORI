# Kubernetes Analytics Hero Standard

## Reference composition

Kubernetes Inventory Overview is the reference composition for Kubernetes Analytics heroes.

Every Analytics hero must contain:

1. domain eyebrow, title, and concise description;
2. no more than **three metadata labels total**;
3. one compact posture panel;
4. no more than two posture metrics;
5. one full-width `Manage Clusters` action;
6. no free-form posture description beneath the posture value.

## Metadata ownership

Metadata must not duplicate posture metrics. For example, an actionable count shown in the posture panel must not also appear in the hero metadata row.

## Dynamic values

Hero helpers use concise semantic context, such as `Node Filesystem`, `Ready-Worker Capacity`, `Namespace Scope`, or a short resource name. Long technical identifiers remain in detailed evidence workspaces and must not be truncated into the hero.

## Overview guidance

`Operational Reading`, `How To Read`, `What To Do`, `Recommended Review Path`, and equivalent interpretation blocks use the Capacity-style icon-led callout. Semantic state is expressed through the icon surface and headline tone, while explanatory text remains neutral.

# Analytics Overview Guidance Standard

All Overview guidance and action regions use the shared `interpretation_callout()` macro.

Applies to:

- Operational Reading
- How To Read
- What To Do
- Recommended Review Path
- Recommended Action
- Operational Triage

Each callout includes an icon, a concise headline, neutral supporting copy, and a semantic tone only when the content represents a Normal, Warning, or Critical state.

# Card and Content Block Standard

A standard content block contains an optional icon, Title Case title, short sentence-case description, content, and no more than two preferred header actions.

Title: 16–18 px semibold. Description: 12–14 px regular and muted. Ordinary card titles use the primary content color, not violet. Cards use a soft border, clean surface, and restrained shadow.

Peer summary cards immediately below tabs use the shared Workspace Summary Card and must have consistent Violet treatment across the row. Do not add a generic page-context card merely to describe the active tab. Use the established semantic component that matches the actual information: Info Flow for a primary ordered sequence, Information Guide Card for non-sequential reference content, Related Page Card for one related destination, or a semantic status block for risk and state. See `WORKSPACE_SUMMARY_CARD.md`.

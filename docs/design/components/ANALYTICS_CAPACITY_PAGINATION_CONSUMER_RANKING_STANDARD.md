# Analytics Capacity, Pagination, and Consumer Ranking Standard

## Per-metric status bars
A parent section may be Warning because one metric is elevated. Each child bar still derives its own color from its own threshold.

## Pagination footer
Canonical footer: `Showing a–b of n` + `Rows` + page-size selector. Scope totals belong in summary evidence, not pagination prose.

## Consumer rankings
Rankings are separated into CPU, Memory, PVC, and Pods tabs. The selected resource occupies the full ranking workspace. Nested tabs do not modify the top-level `tab` query parameter.

# Analytics Overview Posture Header Standard

The Analytics Overview hero context card follows the Inventory context-card grammar:

- one stable card title: `Operational Posture`;
- one semantic status badge at the right;
- no duplicated status value below the title;
- maximum two compact metrics;
- one full-width `Manage Clusters` action.

Status such as Normal, Warning, Critical, or Unknown is displayed once through the semantic badge.

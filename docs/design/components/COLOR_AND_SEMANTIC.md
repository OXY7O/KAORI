# Color and Semantic Standard

Brand violet is reserved for brand emphasis, selection, interaction, focus, hover, and maintenance semantics. Ordinary headings and body text use content colors.

Semantic mapping:
- Normal/healthy: green.
- Information: blue.
- Warning: amber.
- Critical/destructive: red.
- Unknown/disabled: slate.
- Maintenance: violet.
- Pending: cyan.

Color must not be the only status signal. Pair it with text and, when useful, an icon.

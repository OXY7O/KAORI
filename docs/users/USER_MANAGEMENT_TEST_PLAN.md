# User Management Test Plan

Test create, duplicate identity rejection, edit, activate, deactivate, reset password, soft delete, self-protection, admin-level separation of duties, final-super-admin protection, CSRF, permission denial, HTMX and normal redirects, toast-only feedback, Activity Audit persistence, and absence of credentials in metadata.

Future provider tests must cover provider search, immutable identity binding, JIT provisioning, disabled external identity, local override, claim/group reconciliation, duplicate subject prevention, and provider outage behavior.

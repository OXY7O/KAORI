# Authentication UI Reference

This document owns authentication-specific UI decisions. Global color, typography, spacing, accessibility, and component rules remain defined by the Design System.

- The login experience may use a desktop split layout and form-first small-screen layout.
- Keep the complete desktop composition usable at 100% zoom on a 1366×768 viewport.
- Authentication provider actions are shown only when their corresponding flow is implemented and enabled.
- Theme switching remains available before authentication.
- Authentication errors use Critical; successful notices use Normal.
- Security copy may describe real RBAC and audit controls but must not imply unavailable authentication capabilities.
- The brand panel may use a restrained CSS-only infrastructure composition; it is not a global authenticated-page hero reference.
